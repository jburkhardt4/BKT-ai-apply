### 2. Claude Code `2.1.223` now **warns when a subagent's requested model is restricted and the parent model runs instead** — closes a silent model-downgrade gap in `/dispatch` waves  [S122]
**[Recommend: TRACK]**  ·  Theme 2 (loop/dispatch effectiveness) · sharpens ADR-010 / `docs/conventions/model-routing.md`; additive to S86/S99 (`/dispatch` wave orchestration), S97/S68 (model re-baselining)
- **What's new:** `2.1.223` **"Added a warning when workflow agents, forked skills, slash commands, or resumed background agents' requested subagent model is restricted and the parent model runs instead."** Separately, it **added `owner/*` wildcard entries to `strictKnownMarketplaces`/`blockedMarketplaces`** for org-level allow/block of all marketplace repos under a GitHub org (governance primitive for a packaged agent roster, S15/S116).
- **Why it matters for bk-ai-apply:** the whole point of the multi-model routing doctrine is that each `/dispatch` subagent runs on the *right* model per task type. Before this, a wave subagent that requested a specific model but was restricted would **silently fall back to the parent model** — quietly violating ADR-010 with no signal, inflating cost or degrading quality mid-wave. The new warning makes that misconfiguration **observable** the moment a wave runs, which is exactly what you want when authoring `/dispatch` (S06/S45) and re-baselining routing on Opus 5 / Sonnet 5 (S97/S68). The `owner/*` wildcard is a clean governance knob for when the roster is packaged as a marketplace plugin (S15).

When `/dispatch` is authored, treat any "parent model ran instead" warning as a routing-config failure to fix, and reference it in `model-routing.md`. If/when the roster becomes a marketplace (S15), use `owner/*` in managed `strictKnownMarketplaces` to allow only your org.
- **Source(s):** Claude Code changelog — `2.1.223`, Aug 6 2026 ("Added a warning when workflow agents, forked skills, slash commands, or resumed background agents' requested subagent model is restricted and the parent model runs instead"; "Added owner wildcard entries (`\"owner/*\"`) to the `strictKnownMarketplaces` and `blockedMarketplaces` managed settings"). https://code.claude.com/docs/en/changelog
