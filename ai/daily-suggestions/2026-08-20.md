### 1. CC 2.1.236 — pin the scheduled/unattended session's model with `ANTHROPIC_DEFAULT_MODEL` (deterministic model-routing)
- **What's new:** "Added `ANTHROPIC_DEFAULT_MODEL` environment variable: sets the model new sessions
  start on, while a `/model` pick still overrides it and persists across restarts (unlike
  `ANTHROPIC_MODEL`)." (2.1.236, Aug 19, 2026)
- **Why it matters:** This routine and the unattended `/loop` currently **inherit whatever the global
  default model is** — a moving target (Opus 5 became the CC default in S97; the todo-tool removal on
  Opus 4.8/Sonnet 5/Fable 5/Mythos 5+ is model-gated in S148; Auto became the default *permission*
  mode in S157). `ANTHROPIC_MODEL` would hard-pin and block a `/model` override; `ANTHROPIC_DEFAULT_MODEL`
  instead sets a **deterministic starting model** that a human can still override interactively. That's
  exactly the right primitive for a scheduled job whose model choice should be explicit and reproducible
  rather than drifting with Anthropic's default — the direct model-routing analogue of the explicit
  `permissionMode` (S157) and continue-at-limit (S161) decisions already queued for the routine.
- **Concrete change:** decide the routine's canonical model, then set `ANTHROPIC_DEFAULT_MODEL` for the
  scheduled/unattended context (env in the scheduled-task/CI environment, or `env` block in
  `.claude/settings.json` alongside the still-open `permissionMode`/floor work S14/S104/S159). Record
  the choice in `docs/conventions/model-routing.md` / ADR-010 so the pin and the routing table agree.
  Cross-check the choice against S148 (todo-tool availability differs by model).
- **Source:** Claude Code changelog, 2.1.236 (Aug 19, 2026).
