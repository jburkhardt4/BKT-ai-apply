- **What's new:** Claude Code **`2.1.222`** shipped **Aug 4–5 2026**. Two fixes matter directly here: (a) **worktree-isolated sessions and their subagents could run destructive git commands against the main checkout** — isolation now applies to **file edits and Bash in *every* session type**, and it now **blocks subagents redirecting git into the shared checkout via `git -C`, `--git-dir`, or `GIT_DIR`/`GIT_WORK_TREE`**; (b) **PreToolUse auto-allow hooks were bypassing tool restrictions inside background agent tasks** — now fixed.
- **Why it matters for bk-ai-apply:** `/dispatch` is designed to fan out **waves of worktree-isolated subagents**, and the unattended `/loop` leans on **hooks to enforce the CLAUDE.md non-negotiables** (S14) while running background/`/fork` sessions (S77). Both fixes patch exactly those surfaces: before `2.1.222`, an isolated wave-subagent could reach back into the main checkout's git state, and a background task could slip past a PreToolUse auto-allow rule. For an autonomous loop that is *supposed* to keep `main` untouched, this is a release-safety gap, not a nicety.
- **Concrete change (narrow):** set the enforced CLI floor to **`requiredMinimumVersion: "2.1.222"`** in managed settings (the mechanism **S104** introduced), superseding the `2.1.221` floor from S115. No app-code change. Pair with the existing sandbox posture (`sandbox.credentials` S103 · `strictAllowlist` S98 · credential `mask` mode S115). If/when `/dispatch` is authored (S06/S45), assume worktree isolation is now trustworthy for wave fan-out.
