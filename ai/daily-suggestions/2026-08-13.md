### 1. Autonoma — open-source, codebase-aware AI visual-regression agent  `[Recommend: TRACK]`  *(Theme 1 — priority)*
- **What's new:** A visual-regression agent that **reads your codebase** to judge whether a rendered change matches the updated code's *intent* (intentional) or diverges from it (**regression**) — semantic classification instead of raw pixel diffing, explicitly aimed at AI-generated UI churn. Fully **open-source and self-hostable** (Docker Compose + Postgres + Redis) with first-class React / Next.js / Vercel / GitHub / Linear integrations. Actively developed through Jul 2026.
- **Why it matters for bk-ai-apply:** The AI-UAT suite is **behavioral only** (Stagehand assertions); there is still **no visual-regression baseline** anywhere in `e2e/` (S01 `toHaveScreenshot` never adopted; S02 Argos/Lost Pixel only tracked). Autonoma is a third option that fits a heavily AI-authored Tailwind v4 UI and JB's self-host/production bias — semantic noise filtering means fewer false diffs from intended design changes than pixel tools. This is the first genuinely *new* entrant in the visual-validation space since S02.
- **Concrete change (narrow):** Evaluate only, no app-code change. Stand up Autonoma via Docker against a Vercel preview of one screen (e.g. the pipeline board), diff it against the S01 `toHaveScreenshot` path and the S02 hosted-diff option on cost + false-positive rate, and record the pick in an ADR before wiring any visual gate. ### 2. Claude Code 2.1.229 — raise unattended `/loop` `/dispatch` CLI floor to `>=2.1.229`  `[Recommend: IMPLEMENT]`  *(Theme 2 / release safety)*
- **What's new:** 2.1.229 (Aug 12 2026) lands three changes that matter for autonomous runs: (a) **`/commit-push-pr` no longer auto-approves** git/gh commands carrying dangerous flags (`--force`, `--amend`, `--no-verify`, …); (b) **dynamic workflows inside CPU-limited containers** now use the container's CPU limit instead of the host core count; (c) crash fixes for a tool call with a **non-string `glob`/`file_path`/`command`** value and for Windows **extended-length (`\\?\`) / UNC paths**. Sandbox also now brackets IPv6 literals and enforces ambiguous domain spellings **fail-closed** (`/doctor`-flagged).
- **Why it matters for bk-ai-apply:** All three hit this project directly. The commit-flag guard is a release-safety win for any unattended loop that commits (and for this very routine). The container-CPU fix is a **correctness** fix for the Codespaces + dynamic-workflow orchestrator (S07) — wave fan-outs were sizing against host cores. The crash fixes harden headless reliability. This is the established security/reliability floor pattern, superseding S138's 2.1.228 target.
- **Concrete change (narrow):** One line — set `requiredMinimumVersion: "2.1.229"` in managed settings (supersedes S138). **Queued** behind landing `.claude/settings.json` (S14/S104) and behind the GitHub connector for the commit. No agent/logic edits.
- **Source(s):** [Claude Code changelog 2.1.229 — code.claude.com](https://code.claude.com/docs/en/changelog) (Aug 12 2026).
